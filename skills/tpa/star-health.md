# Star Health TPA — Requirements

**Website**: https://www.starhealth.in
**Helpline**: 1800 425 2255
**Network hospitals**: https://www.starhealth.in/network-hospitals

## Planned admission
Submit pre-auth **3–5 days before** the planned admission date (earlier than Medi Assist).

## Emergency admission
Submit pre-auth **within 24 hours** of admission.

## Required fields (Star Health specific)
Star Health requires more fields than most TPAs:
- Patient name (must match policy EXACTLY — even spacing matters)
- DOB, gender, contact number
- **Current address** (required — not optional)
- **PAN number** of proposer (required)
- **CKYC ID** if available
- Policy number + insurer name + TPA name
- Other insurance (yes/no — mandatory field)
- Hospital name, city, email
- Doctor name, qualification, state registration number
- Primary diagnosis + ICD-10 code
- Proposed procedure + ICD-10 PCS code
- Expected stay duration
- Cost breakdown: room, surgeon, anesthesia, OT, investigations, pharmacy, **consumables** (required — not optional)
- Pre-existing disease (yes/no)
- Alcohol/drug related (yes/no)

## Star Health specific notes
- Patient name mismatch with policy is the #1 reason for delays — verify spelling exactly
- PAN number is mandatory (unlike Medi Assist where it's optional)
- CKYC is required if patient is CKYC registered
- Consumables line item in the cost breakdown is required
- Star Health verifies network hospital status before processing — confirm the hospital is on their network
- Doctors must have valid state council registration number in the correct format (e.g. MH-XXXXX for Maharashtra)

## Common Star Health rejection reasons
1. Patient name doesn't match policy records (middle name, initials)
2. PAN number missing
3. Consumables not included in cost breakdown
4. Hospital not in Star Health network
5. CKYC required but not provided
