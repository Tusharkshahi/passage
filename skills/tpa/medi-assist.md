# Medi Assist TPA — Requirements

**Website**: https://mediassisttpa.in
**Helpline**: 1800 425 9559
**Pre-auth submission**: https://m.mediassist.in

## Planned admission
Submit pre-auth **48–72 hours before** the planned admission date.

## Emergency admission
Submit pre-auth **within 24 hours** of admission.

## Required fields (Medi Assist specific)
- Patient name, DOB, gender, contact, email
- Policy number + insurer name
- Hospital name, city, email
- Doctor name, qualification, state registration number
- Primary diagnosis + ICD-10 code (`f.1` on form)
- Procedure + ICD-10 PCS code (`i.1` on form)
- Expected stay duration
- Cost breakdown: room, surgeon, anesthesia, OT, investigations, pharmacy
- Pre-existing disease (yes/no)
- Alcohol/drug related (yes/no)

## Specific notes
- The form explicitly asks for ICD-10 codes in fields `f.1` and `i.1` — these cannot be blank
- Email field is optional but recommended for faster communication
- Patient address and PAN are optional for Medi Assist (unlike Star Health)
- Medi Assist does NOT require CKYC ID

## Common Medi Assist rejection reasons
1. `f.1` (ICD-10 code) or `i.1` (procedure code) left blank
2. Procedure code incompatible with diagnosis code
3. Missing OT charges in cost breakdown
4. Pre-existing disease question not answered
